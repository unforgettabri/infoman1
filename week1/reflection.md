# Reflection 

Running a standalone MySQL server helped me understand why databases are more useful than traditional file-based systems. In a file-based system, data can be scattered across different files, which may lead to duplicate information and errors when several people try to update it. MySQL provides a centralized way to manage data and helps keep information consistent. I also learned that creating an ERD before writing SQL is important because it allows us to organize entities and relationships properly. Doing this early can help prevent problems and unnecessary changes later.

Another thing I realized is that security and access control are important responsibilities of a DBA, especially when the database contains real student information. Although we are currently using the root administrative account, I understand that this would not be a good practice in an actual working environment. Giving everyone full access could put sensitive records at risk. A DBA should create separate user accounts, assign appropriate permissions, and make sure that users can only access the information they need. This activity made me realize that managing a database is not only about storing data, but also about keeping it organized, consistent, and secure.
